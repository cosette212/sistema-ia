Sistema de IA
Proyecto de práctica para la materia Arquitectura de Sistemas de Inteligencia Artificial.

Descripción del proyecto
Este proyecto simula la estructura inicial de un sistema de Inteligencia Artificial. 
Su finalidad es practicar el uso de Git y GitHub para administrar archivos, registrar cambios y trabajar con versiones de un proyecto.

Objetivo
Aprender a utilizar Git y GitHub mediante la creación de commits, consulta del historial, manejo de archivos y colaboración en un repositorio.

Componentes
- Modelo
- Inferencia
- Configuración
- Documentación

Tecnologías
- Python
- Git
- GitHub
- Visual Studio Code
